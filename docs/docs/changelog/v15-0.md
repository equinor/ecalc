# eCalc v15.0

## Breaking changes {/* #breaking-changes */}

- Chart curves must have strictly decreasing head as rate increases. Curves with increasing or equal head values, including all-zero curves, are rejected. Generic compressor charts also require design rate and design head greater than zero. See the [migration guide](../about/migration_guides/v14.0_to_v15.0.md).
