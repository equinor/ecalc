# eCalc v14.0

There are no breaking changes in this release. The chart head validation was planned for v14.0, but was reverted before release and is introduced in [v15.0](./v15-0.md) instead.

## Bug Fixes {/* #bug-fixes */}

- Improved error message when chart headers are missing.
- Invalid charts loaded from a resource file now report the resource file as the source of the error, instead of the YAML referencing it.
