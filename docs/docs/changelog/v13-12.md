# eCalc v13.12

## Bug Fixes {/* #bug-fixes */}

- Fixed infinite loop in the common ASV single-speed compressor solver.
- Validate pressures before computing pressure ratios in simplified compressor trains — prevents division-by-zero errors.
- Improved error message when there are no overlapping periods between time series and model periods.
