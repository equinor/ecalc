# YAML_VERSION 4

This page lists the YAML configuration changes introduced in `YAML_VERSION: 4`, compared to the
previous version. See the [YAML Reference](../about/yaml-reference.mdx) for the full, current schema across all
versions.

## Added

- [`DEFINITIONS` › `COMPRESSOR_MODELS`](../about/yaml-reference.mdx#compressor_models)
- [`PROCESS_PIPELINES` › `PROCESS_UNITS` › `COMPRESSOR` › `MODEL`](../about/yaml-reference.mdx#process_pipelines-process_units)
- [`ENERGY_NETWORK` › `UNITS` › `GENERATOR` › `EVENTS`](../about/yaml-reference.mdx#energy_network-units-generator-events)
- [`ENERGY_NETWORK` › `UNITS` › `DRIVE_TRAIN` › `MECHANICAL_EFFICIENCIES`](../about/yaml-reference.mdx#energy_network-units-drive_train-mechanical_efficiencies)
- [`TIMELINE`](../about/yaml-reference.mdx#timeline)

## Changed

- [`DEFINITIONS` › `PROCESS_UNITS`](../about/yaml-reference.mdx#process_units): Compressors can no longer be defined here. Other process units are defined inline in PROCESS_PIPELINES > PROCESS_UNITS.
- [`PROCESS_PIPELINES` › `PROCESS_UNITS` › `COMPRESSOR` › `TARGET`](../about/yaml-reference.mdx#process_pipelines-process_units): Other PROCESS_UNITS can no longer be defined with TARGET.
- [`PROCESS_PIPELINES` › `EVENTS` › `CHANGE_FROM`](../about/yaml-reference.mdx#process_pipelines-events): No longer in use. Remove. This is detected automatically.

## Removed

- [`DEFINITIONS` › `PROCESS_UNITS`](../about/yaml-reference.mdx#process_units): replaced by [`DEFINITIONS` › `COMPRESSOR_MODELS`](../about/yaml-reference.mdx#compressor_models)
- [`PROCESS_PIPELINES` › `PROCESS_UNITS` › `COMPRESSOR` › `TARGET`](../about/yaml-reference.mdx#process_pipelines-process_units): replaced by [`PROCESS_PIPELINES` › `PROCESS_UNITS` › `MODEL`](../about/yaml-reference.mdx#process_pipelines-process_units)
- [`PROCESS_PIPELINES` › `EVENTS` › `CHANGE_FROM`](../about/yaml-reference.mdx#process_pipelines-events)
- [`ECALC_EVENTS`](../about/yaml-reference.mdx#ecalc_events): replaced by [`TIMELINE` › `EVENTS`](../about/yaml-reference.mdx#timeline-events)
- [`PROCESS_EVENTS`](../about/yaml-reference.mdx#process_events): replaced by [`TIMELINE` › `EVENTS`](../about/yaml-reference.mdx#timeline-events)
