# YAML_VERSION 4

This page lists the YAML configuration changes introduced in `YAML_VERSION: 4`, compared to the
previous version. See the [YAML Reference](../about/yaml-reference.mdx) for the full, current schema across all
versions.

## Added

- [`DEFINITIONS` › `COMPRESSOR_MODELS`](../about/yaml-reference.mdx#compressor_models)
- [`PROCESS_PIPELINES` › `PROCESS_UNITS` › `COMPRESSOR` › `MODEL`](../about/yaml-reference.mdx#process_pipelines-process_units)
- [`TIMELINE`](../about/yaml-reference.mdx#timeline)

## Changed

- [`DEFINITIONS` › `PROCESS_UNITS`](../about/yaml-reference.mdx#process_units): Compressors can no longer be defined here. Use DEFINITIONS > COMPRESSOR_MODELS instead. Other process units are defined inline in PROCESS_PIPELINES > PROCESS_UNITS.
- [`PROCESS_PIPELINES` › `PROCESS_UNITS` › `COMPRESSOR` › `TARGET`](../about/yaml-reference.mdx#process_pipelines-process_units): Use PROCESS_UNITS > MODEL for compressors instead. Other PROCESS_UNITS can no longer be defined with TARGET.
- [`PROCESS_PIPELINES` › `EVENTS` › `CHANGE_FROM`](../about/yaml-reference.mdx#process_pipelines-events): No longer in use. Remove. This is detected automatically.
- [`ECALC_EVENTS`](../about/yaml-reference.mdx#ecalc_events): Use TIMELINE > EVENTS instead.
- [`PROCESS_EVENTS`](../about/yaml-reference.mdx#process_events): Use TIMELINE > EVENTS instead.

## Removed

- [`DEFINITIONS` › `PROCESS_UNITS`](../about/yaml-reference.mdx#process_units)
- [`PROCESS_PIPELINES` › `PROCESS_UNITS` › `COMPRESSOR` › `TARGET`](../about/yaml-reference.mdx#process_pipelines-process_units)
- [`PROCESS_PIPELINES` › `EVENTS` › `CHANGE_FROM`](../about/yaml-reference.mdx#process_pipelines-events)
- [`ECALC_EVENTS`](../about/yaml-reference.mdx#ecalc_events)
- [`PROCESS_EVENTS`](../about/yaml-reference.mdx#process_events)
