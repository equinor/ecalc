# YAML_VERSION 3

This page lists the YAML configuration changes introduced in `YAML_VERSION: 3`, compared to the
previous version. See the [YAML Reference](../about/yaml-reference.mdx) for the full, current schema across all
versions.

## Added

- [`DEFINITIONS` › `COMPRESSOR_MODELS`](../about/yaml-reference.mdx#compressor_models)
- [`COMPRESSORS`](../about/yaml-reference.mdx#compressors)
- [`PROCESS_PIPELINES` › `PROCESS_UNITS` › `COMPRESSOR_PROCESS_UNIT` › `COMPRESSOR`](../about/yaml-reference.mdx#process_pipelines-process_units)
- [`ENERGY_NETWORK` › `UNITS` › `ELECTRICAL_CONSUMER` › `LOAD` › `CURVE` › `POWERCURVE`](../about/yaml-reference.mdx#energy_network-units-electrical_consumer-load-curve)
- [`ENERGY_NETWORK` › `UNITS` › `MECHANICAL_CONSUMER` › `LOAD` › `CURVE` › `POWERCURVE`](../about/yaml-reference.mdx#energy_network-units-mechanical_consumer-load-curve)
- [`ENERGY_NETWORK` › `UNITS` › `FUEL_GAS_CONSUMER` › `RATE` › `CURVE` › `FUELTABLE`](../about/yaml-reference.mdx#energy_network-units-fuel_gas_consumer-rate-curve)
- [`ENERGY_NETWORK` › `UNITS` › `DIESEL_CONSUMER` › `RATE` › `CURVE` › `FUELTABLE`](../about/yaml-reference.mdx#energy_network-units-diesel_consumer-rate-curve)
- [`ENERGY_NETWORK` › `UNITS` › `COMPRESSOR_SAMPLED` › `COMPRESSOR`](../about/yaml-reference.mdx#energy_network-units)

## Changed

- [`DEFINITIONS` › `PROCESS_UNITS`](../about/yaml-reference.mdx#process_units): Compressors can no longer be defined here. Use DEFINITIONS > COMPRESSOR_MODELS instead.
- [`ENERGY_NETWORK` › `UNITS` › `ELECTRICAL_CONSUMER` › `LOAD`](../about/yaml-reference.mdx#energy_network-units-electrical_consumer-load): Added support to also load from curve.
- [`ENERGY_NETWORK` › `UNITS` › `MECHANICAL_CONSUMER` › `LOAD`](../about/yaml-reference.mdx#energy_network-units-mechanical_consumer-load): Added support to also load from curve.
- [`ENERGY_NETWORK` › `UNITS` › `FUEL_GAS_CONSUMER` › `RATE`](../about/yaml-reference.mdx#energy_network-units-fuel_gas_consumer-rate): Added support to also load from curve.
- [`ENERGY_NETWORK` › `UNITS` › `DIESEL_CONSUMER` › `RATE`](../about/yaml-reference.mdx#energy_network-units-diesel_consumer-rate): Added support to also load from curve.

## Deprecated

- [`PROCESS_PIPELINES` › `PROCESS_UNITS` › `COMPRESSOR_PROCESS_UNIT` › `TARGET`](../about/yaml-reference.mdx#process_pipelines-process_units)

## Removed

- [`FACILITY_INPUTS`](../about/yaml-reference.mdx#facility_inputs)
- [`FLUID_MODELS`](../about/yaml-reference.mdx#fluid_models)
- [`MODELS`](../about/yaml-reference.mdx#models)
- [`FUEL_TYPES`](../about/yaml-reference.mdx#fuel_types)
- [`PROCESS_PIPELINES` › `PROCESS_UNITS` › `COMPRESSOR_PROCESS_UNIT` › `SHAFT`](../about/yaml-reference.mdx#process_pipelines-process_units)
- [`INSTALLATIONS`](../about/yaml-reference.mdx#installations)
