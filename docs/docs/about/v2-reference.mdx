# Schema v2 Reference

This page documents all YAML configuration keys available for yaml version `2`, filtered by YAML_VERSION
rather than a fixed list of top-level sections.

Elements are labelled with their lifecycle: <LifecycleBadge kind="introduced" version="2" /><LifecycleBadge kind="deprecated" version="2" /><LifecycleBadge kind="removed" version="2" />. Use the filters below to focus on what you need.

<div data-lifecycle-section>

## YAML_VERSION

The eCalc YAML schema major version. Determines which root elements are available. Only the major version is tracked, e.g. YAML_VERSION: 2 allows any 2.x.y root elements. Defaults to 1 if not specified.

### TURBINES

Defines gas turbines that can be referenced from GAS_TURBINE units in the ENERGY_NETWORK. Fuel follows the efficiency curve: demand below the first LOAD burns the fuel of the first LOAD, and the last efficiency is used above the last LOAD. The last LOAD is the maximum power, which is the capacity of a GAS_TURBINE.

<YamlCodeBlock>{"LOWER_HEATING_VALUE: 38.0\nCURVE:\n  LOAD:\n  - 2.352\n  - 4.589\n  - 6.853\n  EFFICIENCY:\n  - 0.138\n  - 0.21\n  - 0.255"}</YamlCodeBlock>

#### LOWER_HEATING_VALUE

Lower heating value [MJ/Sm3] of the fuel.

#### CURVE

Load and efficiency values, given directly or in a FILE with LOAD and EFFICIENCY columns.

### GENERATORS

Defines generators that can be referenced from GENERATOR units in the ENERGY_NETWORK. Fuel is interpolated from the POWER/FUEL curve. Below the first POWER the lowest FUEL is used, and above the last POWER the highest FUEL is used. The last POWER is the maximum power, which is the capacity of a GENERATOR.

<YamlCodeBlock>{"CURVE:\n  POWER:\n  - 0.0\n  - 5.0\n  - 10.0\n  - 15.0\n  FUEL:\n  - 0.0\n  - 25000.0\n  - 48000.0\n  - 70000.0"}</YamlCodeBlock>

#### CURVE
