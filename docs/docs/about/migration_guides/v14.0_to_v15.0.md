# v14.0 to v15.0

### Migration overview {/* #migration-overview */}

#### Make chart head strictly decrease with increasing rate {/* #make-chart-head-strictly-decrease */}

Chart curves must have strictly decreasing head values as rate increases. Earlier versions logged a warning when head
increased with rate and continued the calculation. In v15.0, curves with increasing or equal head values, including
all-zero curves, are rejected.

This applies to single-speed and variable-speed pump and compressor charts, both when curves are defined directly in
YAML and when they are loaded from a file. For variable-speed charts, the requirement applies independently to every
speed curve.

Review each curve in ascending rate order and update or remove points so that head strictly decreases as rate increases.

**Invalid/old:**
```yaml
RATE: [1000, 2000, 3000]
# This is old
HEAD: [100, 100, 80]
```

**Valid/new:**
```yaml
RATE: [1000, 2000, 3000]
# This is new
HEAD: [105, 95, 80]
```

#### Use positive generic compressor chart design values {/* #use-positive-generic-chart-design-values */}

Generic compressor charts can only be created when both design rate and design head are greater than zero.

For `GENERIC_FROM_DESIGN_POINT`, set `DESIGN_RATE` and `DESIGN_HEAD` to positive values.

For GENERIC_FROM_INPUT, eCalc derives the design values from the input rate and head values. 
The calculation now fails if the derived design rate or design head is zero, instead of creating an all-zero chart.
