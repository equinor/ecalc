# YAML changelog, In development (v5)

This page lists the YAML configuration changes introduced in `YAML_VERSION: 5`, compared to the
previous version. See the [YAML Reference](../yaml-reference.mdx) for the full, current schema across all
versions.

## Added

- [`ENERGY_NETWORK` › `UNITS` › `GENERATOR` › `EVENTS`](../yaml-reference.mdx#energy_network-units-generator-events)

## Changed

- [`ENERGY_NETWORK` › `UNITS` › `DRIVE_TRAIN`](../yaml-reference.mdx#energy_network-units): Removed NAME. A drive train is identified by SHAFT.
- [`ENERGY_NETWORK` › `UNITS` › `COMPRESSOR_SAMPLED`](../yaml-reference.mdx#energy_network-units): Removed NAME, the unit is named by COMPRESSOR. FILE must have a SHAFT_POWER column instead of FUEL and/or POWER, and INPUT must provide mechanical power.
