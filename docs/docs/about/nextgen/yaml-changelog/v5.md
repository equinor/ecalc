# YAML changelog, In development (v5)

This page lists the YAML configuration changes introduced in `YAML_VERSION: 5`, compared to the
previous version. See the [YAML Reference](../yaml-reference.mdx) for the full, current schema across all
versions.

## Added

- [`ENERGY_NETWORK` › `SOURCES` › `LOWER_HEATING_VALUE`](../yaml-reference.mdx#sources)
- [`ENERGY_NETWORK` › `UNITS` › `GENERATOR` › `EVENTS`](../yaml-reference.mdx#energy_network-units-generator-events)

## Changed

- [`DEFINITIONS` › `TURBINES` › `LOWER_HEATING_VALUE`](../yaml-reference.mdx#lower_heating_value): Set it on the fuel/diesel source this unit draws from instead.

## Removed

- [`DEFINITIONS` › `TURBINES` › `LOWER_HEATING_VALUE`](../yaml-reference.mdx#lower_heating_value): replaced by [`ENERGY_NETWORK` › `SOURCES` › `LOWER_HEATING_VALUE`](../yaml-reference.mdx#sources)
